ERONIX Distribution
===================

This folder is outside the source project and contains platform-specific
builds when available:

  linux/    Linux x86_64 desktop shortcut helper
  windows/  Windows build output (requires a Windows build host)
  android/  Android APK

The desktop and Android apps display "Copyright 2026 Eng. Omar Abdelaziz";
the name links to:
  https://engomarabd-elaziz.github.io/My-Portofolio/

Linux and Windows application images are built on their native GitHub Actions
runners when a version tag is pushed, then attached to that GitHub release.
The Linux application image is not checked into the source repository because
its bundled runtime exceeds GitHub's per-file size limit.

Install the Android APK by opening it on an Android 14 (API 34) or newer
device. Android may ask permission to install apps from the selected source.

The Windows output folder is prepared, but a native Windows .exe application
image cannot be generated by the Linux packaging toolchain. Build it on
Windows by running scripts/package-windows.ps1 from the source project.
