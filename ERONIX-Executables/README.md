## What is in this folder?

- `android/ERONIX.apk` — Android installation package retained with the
  repository.
- `linux/create-desktop-shortcut.sh` — desktop shortcut helper for a Linux
  application image.
- `windows/BUILD-WINDOWS.txt` — notes for producing a native Windows build.

The complete desktop app images are generated on native Linux and Windows
GitHub Actions runners and attached to each version release. They bundle the
Java runtime and are intentionally not committed to this source repository.

For Android, install the downloaded APK on Android 14 (API 34) or newer. The
device may ask you to allow installation from the browser or file manager you
used to download it.
