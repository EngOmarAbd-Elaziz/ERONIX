## What’s new

- **Desktop UI scroll & rendering performance optimization:**
  - Isolated and cached card drop-shadow backdrops (`two-pass-box`) so live updates and scrolling no longer trigger per-frame Gaussian blur passes.
  - Coalesced simulation UI updates, removed full `ListView.refresh()` calls, reused `EventCell` and `RoomCard`/`SeatSlot` nodes, and throttled progress bar updates.
  - Added seamless nested scroll forwarding from the event timeline to the main dashboard and capped displayed timeline rows while preserving full event history for reports.
- **Improved desktop simulation flow:**
  - Automatically scrolls smoothly to the live Waiting Room & Doctors view when starting a simulation.
  - Fixed **Reset** (and **Stop**) focus handling so the dashboard scroll position stays put.
- **Android navigation polish:**
  - Pressing **Start** on mobile now switches directly to the **Home** overview tab.
